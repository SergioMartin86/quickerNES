Save states

Two tests start from a save state of a game this repository cannot contain (microMachines.race20, saiyuukiWorld.lastHalf). The states are not in the repository either: a state is the game's memory. Keep them beside the tests on the machine that has the games; the tests that use them are only built with -DonlyOpenSource=false.
